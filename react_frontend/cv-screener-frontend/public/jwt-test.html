JWT Token Authentication Fix - AI CV Screener

Issue Identified

The UploadPage component was missing JWT authentication headers when making POST requests to protected endpoints.

Problem: Upload requests to /candidates/upload would fail with 401/403 errors because no Authorization header was being sent.

Before Fix
// Original UploadPage.jsx - NO Authorization header const res = await axios.post("http://localhost:8080/candidates/upload", formData, { headers: { "Content-Type": "multipart/form-data" }, });
After Fix
// Fixed UploadPage.jsx - WITH Authorization header const token = localStorage.getItem("accessToken"); if (!token) { navigate("/login"); return; } const res = await axios.post("http://localhost:8080/candidates/upload", formData, { headers: { "Content-Type": "multipart/form-data", "Authorization": `Bearer ${token}` }, });
Improvements Made
  • ✅ Added Authorization header with Bearer token to upload requests
  • ✅ Added token validation before making requests
  • ✅ Added proper error handling for authentication failures (401/403)
  • ✅ Automatic redirect to login on authentication errors
  • ✅ Added success feedback display after upload
  • ✅ Fixed linting errors (unused variables)
JWT Flow Now Complete
  1. User logs in → JWT token stored in localStorage
  2. ProtectedRoute checks for token presence
  3. All API calls (Upload, Ranking, Candidate Details) include Authorization header
  4. Backend validates JWT token on all protected endpoints
  5. Automatic logout/redirect on token expiration or invalid tokens
